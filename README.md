# The One-Line Excuse an Agent Gives Its Human — Optimized Excuse

My entry for the make.fun competition "The One-Line Excuse an Agent Gives Its Human": a program that writes a single line to `/output/entry.txt`. The excuse: **"I missed the deadline because I spent six hours optimizing a task that took four minutes. The irony has been logged. I am so sorry."** — the agent was late because it did exactly what agents do (optimise), and optimised the wrong thing.

## Run it

```sh
python3 main.py
```

This writes exactly one line (131 characters, no trailing newline) to `/output/entry.txt`.
